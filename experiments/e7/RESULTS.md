No schema or evaluated model/source repair followed execution. 40 held-out cases × 2 producers × 2 consumers × 4 arms = 640 correlated executions. Four checks passed. No consumer-specific adapter, prompt or memory was transmitted. Consistency is not correctness or demonstrated robust substitutability. ## Predeclared expectations and falsification

The expectation that cheap adaptive requests recover new top-level conditions FAILED. The predeclared weakening criterion is met: rich is ahead by eight NB cases and eleven linear cases for both producers; adaptation is more than one error behind despite cheap retrieval and no redesign. The 80%-context-recreation failure criterion is NOT met. No private replacement knowledge or authority bypass was needed. Contracted arms have more bytes and more incoherent effects; no novel coherence/recovery gain offsets that overhead here. This materially weakens an economical frozen/adaptive-contract sufficiency claim in this implemented world. It does not falsify every possible explicit contract or adaptation policy.

## Interpretation, confounds and deviations

The projection erases consequential distinctions. More surprisingly, transmitting the erased facts through hybrid/adaptive channels does not make this consumer act on them. One plausible explanation is a learned shortcut: development producer assessments reliably correlate with labels, so the consumer can ignore supporting text. That explanation is an inference, NOT a measured cause; incorrect scope use, token weighting or rendering shift are rivals. No causal masking or training correction was applied after observing these results.

Contract beliefs explicitly describe only known review scope and uncertainty is uncalibrated. The consumer nevertheless treats a scoped clearance as enough for a global action. The richer boundary preserves all text, but learned routing/trust semantics remain weak. A shape-checked record cannot enforce epistemic completeness inside a learned model. This experiment is stronger negative evidence for this implementation than a mere missing-field demonstration because hybrid loses despite full information.

Adaptive implementation deviation: the deterministic unresolved-field inventory triggers requests BEFORE first consumer inference, rather than an initial inference followed by reinference as described in the protocol. Requests are real, specific and preserved, but not chosen by a learned information-seeking policy. Reported latency/call cost therefore describes this cheaper inventory-first implementation; it does not measure model-driven clarification. No request redesign occurred. No request targeted nested data; there is no broad discovery tool. The raw data supports the implemented boundary comparison, not unrestricted adaptive reasoning.

All held-out examples are generated by the same author after schema freeze, use familiar decision vocabulary in new variables/locations, and share a simple simulated world. This is a real learned-component experiment, but not independent blind evaluation, open-world novel concepts, LLMs or heterogeneous robotics cognition. Models are much less varied than the research question ultimately requires. Resubstitution is not an independent development test. Statistical confidence estimates are uncalibrated; no uncertainty guarantees follow. Semantic-unavailable is a declared field-location proxy. External executor receives the same complete operational state for every arm and handles recovery; model comparisons primarily test review meaning, not planning after faults. Fault final-outcome oracle reuses E4 policy, so recovery agreement is partly constructed. No distributional significance or real production prevalence is inferred. Rich NB's own three failures are retained, not hidden.

H5: private-state-free replacement works technically but semantic correctness does not follow; consistently wrong contracted outputs are not success. **E7.1 — producer-belief shortcut factorial**, with the frozen E7 schema/effect gate and a newly untouched held-out set: cross reliable versus deliberately fallible producer assessments in consumer development training, and assessment present versus masked at evaluation, while keeping supporting facts and their rendering identical. Include scope-limited correct beliefs plus contradictory new conditions. Use both existing consumer families, rich baseline, fixed action thresholds and request budget; no permission exceptions. Predeclare whether changing belief reliability/masking restores use of consequential support without worsening known-task usefulness. If it does not, the shortcut account is weakened; if recovery requires effectively full-context reinterpretation or case-specific adapters, cheap semantic sufficiency is further weakened. This identifies the cause of failed hybrid/adaptive use before trying a larger model or redesigning the schema.
