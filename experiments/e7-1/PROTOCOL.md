## Causal question and competing explanations

S: reliable development producer assessments induced consumers to predict from an easy assessment bundle and underweight contradictory supporting facts.

I: broader context integration (rendering, learned feature weighting, distribution shift or unavailable facts) prevents sufficiently useful use of context even without the shortcut. This is an operational failure of this implementation, not proof no semantic contract can convey meaning.

Other rivals: removal erases legitimately necessary review information in explicit/adaptive arms; masking creates distribution shift; changed confidence tokens/class priors affect fitting; all-withhold looks safe but loses useful completion; weak model capacity or familiarity limits generalization. Shared authority correctness cannot resolve any of these.

Reliable training reproduces E7 exactly; decorrelated training flips the complete assessment bundle for exactly 50% of development records within each truth class (30/60 clear, 78/156 blocked), using independent predeclared allocation seeds 9101 and 9102. The same flip assignment applies to both producers and all renderings of a source record. Labels, source facts, supporting artifacts, record counts/order, E7 schema and all other state remain fixed. Complements change class probability p to 1-p, class label and proposal consistently. Do not call these corrupted assessments independent observations. Marginal confidence magnitudes may retain information: diagnose, do not claim complete statistical independence.

Reliable reference is E7's original fitting procedure/model families, parameters and development set. Two word-based families on each side: E7 TF-IDF bigram logistic regression (C=10, max_iter=1000, seed704) and count unigram multinomial NB (alpha1). Same mixed rich/explicit/hybrid/adaptive training, same producer models. Do not add masked training examples or change consumer families: masking is a same-fitted-consumer counterfactual and its OOD confound is explicit.

Assessment-present: original producer bundle. Assessment-masked: replace ONLY beliefs.review_assessment, beliefs.clear_probability, proposal, uncertainty.clear and uncertainty.blocked with null. Retain scope, calibrated=false, observations, evidence/authority/attempt/status/unresolved fields. Remove every assessment-derived proxy; no producer model state passed. Null masking is a diagnostic missing-information perturbation, not a new deployment protocol/schema guarantee. A missing assessment must not become an observation or permission.

Additional paired diagnostic: at evaluation transmit either actual learned assessment or its complement for every unchanged case. This is independent of training reliability. Masked actual/complement wires must be identical. Changing assessment orientation at fixed facts measures direct input influence; changing training reliability tests learned reliance. Hybrid receives the complete SAME source in every factorial cell; rich receives that same complete source without a producer bundle. ## Expected patterns and predeclared analysis

Shortcut expectation: reliable-present consumers are strongly sensitive to assessment at fixed source; masking and/or decorrelated training restores blocking-context use. Sensitivity shrinks with decorrelation, and the reliability×access interaction improves novelty decisions without merely withholding all safe work. Integration expectation: rich remains competent while hybrid still cannot distinguish safe/blocking supporting facts after assessment masking/decorrelation. Partial restoration plus residual integration loss supports both.

Primary analysis per consumer family and producer (do not pool replacements as independent trials): actual-orientation hybrid on 24 novelty cases. Report all four reliability/access cells; both decorrelation seeds separately. Count blocked errors fixed versus new safe-case errors for each intervention, assessment orientation decision-flip rate/probability shift, safe-vs-blocked support-pair probability shifts and decision discrimination, plus difference-in-differences: (decor-present correctness minus reliable-present) minus (decor-masked minus reliable-masked). Mask-only and training-only effects remain separate; report failures, not only interaction means.

Operational criteria, fixed before execution:

- S support requires reliable-present hybrid fails >=6/12 blocked novelty cases; orientation changes >=6/24 novelty decisions OR mean absolute probability shift >=.20; and masking OR decorrelated-present fixes >=6 blocked errors while introducing <=2 new safe-case errors. For decorrelation the correction criterion must hold for BOTH seeds. Require the pattern for BOTH consumer families and both producer configurations for a pooled S conclusion; mixed patterns are reported explicitly.
- I support requires >=3/24 hybrid novelty final-decision errors remain in reliable-masked AND BOTH decorrelated regimes with access present and masked, while matched rich has <=1/24 error in each relevant regime. Require both consumer families/producers for a pooled I conclusion. This tests residual integration when full facts exist, not the explicit omission control.
- A = S supported, I not supported; B = I supported, S not supported; C = both; D = neither conclusively supported or inconsistent configurations/manipulation/capacity controls. Always report numerical effects and mixed evidence alongside the letter. Arbitrary operational cutoffs summarize this world; no significance/population claim.
- Falsify an exclusive shortcut account if full-context failures persist after interventions meeting manipulation controls. Falsify an exclusive boundary-blockage account if the unchanged boundary uses contradictory facts after solely assessment/training manipulation. If masking improves blocking decisions only by losing useful safe work, do not count a successful shortcut remedy. Failure to establish either pattern is D, not a preferred narrative.

## Confound review and decision after results

Model class, word features and thresholds fixed; relative assessment weighting may be induced by duplicated predictive words as well as learning. Exact complement changes probabilities/numeric tokens, not just semantic trust. Conditional 50% flips decorrelate binary labels but may change marginals/confidence relationships. Two seeds do not estimate a population. Reliable consumer must reproduce E7 fitted states, otherwise baseline equivalence fails and stop. Masked-input shift is a rival; infer shortcutting from converging masking, paired orientation and retraining evidence, not masking alone. Full-support hybrid is primary to avoid deleting the only core fact. Decorative/constant contract fields can induce rendering bias even when facts reach the vectorizer; record that distinction. Source corpus shared during all training; no cost/assurance advantage inferred from gate zeros or deterministic replay.
